# 🗺️ Ecossistema Inclusivo Unificado - Zeladoria Urbana com IA

Este projeto é uma plataforma automatizada de monitoramento de acessibilidade urbana que conecta cidadãos à gestão pública por meio da tecnologia.

## 🚀 Funcionalidades
- 🤖 **Bot do Telegram:** Central de atendimento inteligente rodando com a IA Google Gemini 3.6 para gerar laudos técnicos automáticos de fotos.
- 🗺️ **Mapa Interativo:** Painel geospacial construído em Flask para visualização de ocorrências registradas em tempo real.
- 📋 **Painel Administrativo:** Tabela de gerenciamento com controle de protocolos de denúncias oficiais e armazenamento de evidências visuais.
- 🕵️‍♂️ **Supervisor de Tempo Real:** Script de varredura contínua a cada 2 segundos para monitoramento de integridade e status de serviços.

## 🛠️ Tecnologias Utilizadas
- Python 3.14
- Flask (Servidor Web)
- Python-Telegram-Bot (API Telegram)
- Google GenAI (Gemini 3.6)
